What it does

One timeline, no duplicates
Posts from Bluesky and Mastodon interleaved chronologically. Simultaneous cross-posts merge automatically (Crosstalk), consecutive boosts can be grouped, keywords or @users can be muted, and your reading position syncs across devices.
Write once (300 / 500)
Dual progress rings track Bluesky (300) and Mastodon (500). Posts between 301 and 500 characters automatically split into a numbered thread on Bluesky while staying a single post on Mastodon. Includes local drafts, post scheduling and @handle mapping.
Media, GIFs & visual cards
Paste or drag up to 4 images with quick crop presets (1:1, 16:9, 4:5), upload video up to 50 MB, search and post animated GIFs natively on both networks, or generate shareable cross-post cards with quoted posts preserved.
Deck or single column
Switch between a focused single feed and a reorderable multi-column Deck with a side thread column. Recent search history, network notification filters, in-app @mentions/#hashtags and full keyboard shortcuts (press ?).
Collections, Reader & DMs
File saved posts into custom collections, read linked articles in Reader View, browse profile Posts/Replies/Media tabs, follow Bluesky feeds and Mastodon lists, and answer unified direct messages.
Optional AI & languages
Generate WCAG-oriented image alt-text and translate posts or notifications inline with a local Ollama instance, Google Gemini (free tier), or an OpenAI-compatible API. Interface in English and Portuguese.

Your computer, your keys.

MastoSky is a self-contained Python server (app.py) and static vanilla HTML/CSS/JS frontend. By default it binds strictly to 127.0.0.1, keeping your Bluesky App Password and Mastodon token on your machine.

Optional --lan and Docker modes restrict access to private RFC 1918 / Tailscale networks with per-session CSRF tokens, host/origin validation, SSRF checks on link fetches, and 0600 credential files.

  • Python 3 standard library
  • No pip, no npm
  • 225+ unit tests · MIT licence

    Extract the file and open MastoSky (first launch on macOS/Windows may ask for confirmation since builds are unsigned). All releases ↗

  2. MastoSky opens automatically at http://127.0.0.1:8000. Sign in directly with your Bluesky account (password or App Password, with 2FA support) and Mastodon (1-click OAuth).

  3. To use on iPhone, iPad or Android over local Wi-Fi or Tailscale, open the phone icon in the top bar (or start with --lan) and scan the QR code to install as a PWA:

    python3 app.py --lan
    Advanced: Install via Terminal, Git or Docker

    One-line installer (macOS / Linux):

    curl -fsSL https://raw.githubusercontent.com/gjmcosta/MastoSky/main/install.sh | bash

    One-line installer (Windows PowerShell):

    irm https://raw.githubusercontent.com/gjmcosta/MastoSky/main/install.ps1 | iex

    Or clone and run with Python 3:

    git clone https://github.com/gjmcosta/MastoSky.git
cd MastoSky
python3 app.py --open

    Or deploy always-on with Docker / CasaOS (docker compose up -d) for automatic sync via user_data.json and Tailscale access.
